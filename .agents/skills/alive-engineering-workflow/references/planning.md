# Plan Mode

Use this mode before a cross-layer change, migration, architectural refactor, release gate, or ambiguous feature.

## Required plan sections

```md
## 목표
## 가정
## 범위
## 제외 범위
## 영향 경로
## 구현 단계
## 성공 조건
## 검증 계획
## 위험과 롤백
```

Save the plan under `documents/plans/` using the project's front matter and Korean documentation rules. Keep plans implementation-sized; do not write a broad roadmap for a one-file change.
