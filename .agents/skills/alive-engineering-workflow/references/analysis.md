# Analyze Mode

Use this mode for project analysis, architecture investigation, feature feasibility, and improvement recommendations.

## Rules

- Inspect before proposing.
- Cite concrete files, symbols, tests, commands, and current runtime evidence.
- Separate facts, inferences, assumptions, and unknowns.
- Do not edit application code.
- Do not turn historical reports into current facts without checking source and tests.
- Prefer the smallest useful recommendation and identify tradeoffs.

## Output

1. Current state.
2. Evidence.
3. Risks and missing verification.
4. Options and tradeoffs.
5. Recommended path.
6. Success criteria for the next task.
