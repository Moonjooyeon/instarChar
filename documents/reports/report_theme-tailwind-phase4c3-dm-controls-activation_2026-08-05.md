# 테마·Tailwind 4차 C-3 DM 제어·입력 및 활성화 보고서

## 작업 범위

- 자동 대화 방식, 시작·중지, 화자 선택과 설명 입력을 전환했다.
- 이미지 미리보기, 첨부, 메시지 입력과 전송·비활성 상태를 전환했다.
- `DmThreadRoute`에 라이트·다크 테마 범위를 활성화했다.

## 디자인 판단

- 자동 대화 시작은 포인트 보조 액션, 중지는 위험 액션으로 명확히 구분했다.
- LIVE 상태는 성공 의미색과 텍스트·점 표시를 함께 유지하고 고정 핑크 그림자를 제거했다.
- 화자 선택은 같은 중립 칩에서 선택된 항목만 포인트 표면으로 바꿨다.
- 입력 영역은 올라온 표면과 명확한 경계로 메시지 읽기 영역과 분리했다.
- 전송 버튼은 주 액션, 이미지 첨부는 보조 액션으로 위계를 유지했다.

## Tailwind 전환

- 자동 대화 시작·중지, 이미지 첨부, 메시지 전송의 기본·호버·비활성 상태를 Tailwind 유틸리티로 옮겼다.

## 활성화 범위

- 대화방 헤더와 메시지
- 관계·기억 패널
- 자동 대화와 화자 선택
- 이미지와 메시지 입력

공통 설정·신고·교정 모달은 대화방 루트 밖에서 렌더링되므로 이후 모달 단계에서 전환한다.

## 검증

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`
- `dm-thread.css` 직접 색상 검사

실행 중인 프론트엔드가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다. 실제 대화 흐름의 라이트·다크 검토는 실행 중인 앱이 제공될 때 수행해야 한다.
