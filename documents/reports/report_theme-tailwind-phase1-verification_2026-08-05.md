# 테마 및 Tailwind CSS 전환 1차 검증 보고서

## 작업 범위

- Tailwind CSS v4.3.3과 Vite 플러그인 추가
- 런타임 CSS 문자열 주입을 정적 CSS 진입점으로 전환
- 라이트·다크 의미 기반 색상 토큰 추가
- 기기 설정, 라이트, 다크 선택과 로컬 저장 구현
- 홈 화면 색상 토큰화 및 테마 선택기를 Tailwind 유틸리티로 구현
- 미전환 화면을 기존 다크 테마로 격리하는 `al-theme-ready` 경계 추가

## 시각 검증 상태

검증 시점에 프론트엔드 실행 프로세스가 없었다. 프로젝트 규칙에 따라 새 앱 프로세스를 시작하지 않았으므로 실제 화면 검증은 보류 상태다.

## 실행 화면 검토 절차

이미 실행 중인 앱이 준비되면 다음 순서로 확인한다.

1. 390×844 모바일 뷰에서 캐릭터가 없는 홈을 연다.
2. `기기 설정`, `라이트`, `다크`를 차례로 선택해 배경, 본문, 구분선, 첫 캐릭터 버튼, 미리 보기 버튼을 확인한다.
3. 새로고침 후 선택 모드가 유지되는지 확인한다.
4. 브라우저 개발자 도구에서 `html[data-theme]`와 `localStorage['alive-theme']`가 선택과 일치하는지 확인한다.
5. 기기 설정을 선택하고 운영체제 색상 모의를 바꿔 즉시 테마가 따라가는지 확인한다.
6. 캐릭터가 있는 홈에서 캐릭터 카드, 프로필 수정, 삭제, 새 캐릭터 버튼의 hover와 focus 상태를 확인한다.
7. 라이트 모드에서 피드나 DM으로 이동했을 때 미전환 화면이 기존 다크 표현을 유지하고 텍스트가 사라지지 않는지 확인한다.
8. 430px 이하에서 외곽 여백과 프레임 모서리가 제거되고 safe area가 유지되는지 확인한다.
9. 키보드만 사용해 세 가지 테마 버튼을 이동하고 선택할 수 있는지 확인한다.
