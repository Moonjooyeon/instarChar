# 다크 모드 단일 운영 전환 보고서

## 결과

- 로그인과 홈 상단의 라이트·다크 전환 버튼을 제거했다.
- 앱 시작 시 기존 `alive-theme` 저장값을 삭제하고 다크 테마를 강제로 적용한다.
- 불필요해진 테마 상태 훅과 라우트 간 테마 속성 전달을 제거했다.
- 추후 라이트 모드를 다시 도입할 수 있도록 라이트 색상 토큰과 테마 색상 정의는 보존했다.
- 최근 추가된 크레딧 바로가기와 크레딧 스토어 경로는 변경하지 않았다.

## 검증

| 항목 | 결과 |
|------|------|
| TypeScript 타입 검사 | 통과 |
| 도메인 테스트 | 122개 통과 |
| Vite 프로덕션 빌드 | 통과 |
| 실행 화면 확인 | 실행 중인 프런트엔드 프로세스가 없어 미실시 |

## 수동 확인 가이드

이미 실행 중인 개발 환경에서 다음 항목을 확인한다.

1. 로그인 화면 상단에 테마 전환 아이콘이 표시되지 않는다.
2. 홈 계정 바에 테마 전환 아이콘이 표시되지 않는다.
3. 브라우저 저장소의 `alive-theme` 값을 `light`로 지정한 뒤 새로고침해도 다크 화면으로 열린다.
4. 홈의 크레딧 바로가기와 로그아웃 버튼이 정상적으로 동작한다.
