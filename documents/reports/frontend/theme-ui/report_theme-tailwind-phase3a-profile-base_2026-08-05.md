# 테마 및 Tailwind CSS 전환 3차 A 프로필 기본 영역 보고서

## 작업 범위

- 피드 프로필의 배너, 아바타 경계, 이름, 아이디, 소개, 첫 글 안내 토큰화
- 세계관 칩, 프로필 도구 버튼, 팔로우 통계, 갤러리 기본 상태 토큰화
- 대화 버튼과 프로필 확장 버튼에 Tailwind 유틸리티 적용
- `al-feed-theme-ready` 활성화 전용 스타일 경계 작성

## 활성화 정책

프로필만 라이트로 바꾸면 아래 작성기와 타임라인이 기존 다크 화면으로 남는다. 이 혼합 화면을 사용자에게 노출하지 않기 위해 `al-feed-theme-ready` 클래스는 아직 `FeedRoute`에 추가하지 않았다.

다음 항목이 준비된 뒤 피드 전체에 한 번만 활성화한다.

- 관계·기억 확장 패널
- 작성기와 자동 글 설정
- 타임라인, 게시물, 댓글
- 피드 도움말 포털
