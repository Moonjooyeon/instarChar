# 테마·Tailwind 7차 A 진입 동선 액션 보고서

## 작업 범위

- 인증 로딩·복구와 Toss 로그인 주·보조 액션을 전환했다.
- 홈의 로그아웃, 캐릭터 추가, 첫 캐릭터 생성, 서비스 미리보기 액션을 전환했다.
- 서비스 투어의 뒤로·이전·다음 액션을 전환했다.
- 캐릭터 최종 확인의 재시도·뒤로·저장 액션을 전환했다.

## 디자인 판단

- 주 행동은 브랜드 포인트 면, 보조 행동은 중립 표면과 테두리로 통일했다.
- 비활성 저장·로그인 액션은 명도와 텍스트를 함께 낮춰 상태를 색 하나에 의존하지 않게 했다.
- Google·Apple 로그인은 공식 브랜드 자산과 색상을 그대로 보존했다.

## Tailwind 전환

진입 동선에서 사용자가 실제로 누르는 핵심 버튼의 기본·호버·비활성 색상 상태를 시맨틱 Tailwind 유틸리티로 옮겼다. 반복 클래스는 각 화면 파일의 명시적 상수로 관리한다.

## 검증

- 핵심 진입 액션의 Tailwind 클래스 사용을 정적 계약 테스트로 고정했다.
- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`

실행 중인 프론트엔드가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다.

## 다음 단위

- 전체 정적 완료 감사를 문서화하고 실행 화면 검토 절차를 갱신한다.
