# 테마·Tailwind 5차 A 공통 모달 셸 전환 보고서

## 작업 범위

- 채팅방 이름, 초기 이름, 캐릭터 삭제 모달을 전환했다.
- 페르소나 편집과 캐릭터 해석 교정 모달을 전환했다.
- 약관 동의와 콘텐츠 신고 모달을 전환했다.
- 공개 프로필, 세계관, 팔로우와 DM 설정 모달은 제외했다.

## 구조 판단

모달은 화면 루트의 형제 영역에서 렌더링되므로 현재 화면의 테마 변수를 안정적으로 상속하지 않는다. 공통 `.al-modal` 셸을 쓰는 배경 레이어에 `al-theme-ready al-common-modal-theme-ready`를 직접 추가해 독립 테마 범위를 제공했다.

## 디자인 판단

- 모달 배경은 공통 `scrim`, 카드에는 휴대폰 표면과 프레임 그림자를 사용했다.
- 입력과 취소는 중립 표면, 저장은 포인트, 삭제·신고는 위험 의미로 통일했다.
- 교정 UI의 주황 전용 팔레트를 제거하고 정보성 포인트 상태로 정리했다.
- 약관 링크와 보조 문구는 포인트·약한 텍스트 토큰으로 대비를 맞췄다.

## 검증

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`
- `common-modals.css` 직접 색상 및 제외 셀렉터 검사

실행 중인 프론트엔드가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다.
