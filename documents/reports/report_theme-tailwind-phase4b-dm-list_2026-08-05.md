# 테마·Tailwind 4차 B DM 목록 화면 전환 보고서

## 작업 범위

- DM 목록 헤더, 빈 상태, 대화 항목과 수정·삭제 액션을 전환했다.
- 나와 바로 대화하기, 캐릭터끼리 만나게 하기, 상대 선택 패널을 전환했다.
- DM 대화방의 메시지, 관계·기억 패널과 입력기는 포함하지 않았다.

## 디자인 판단

- 대화 항목은 구분선 중심의 가벼운 목록으로 유지하고 호버 시에만 중립 표면을 드러냈다.
- 메시지 수는 강한 배지 대신 옅은 포인트 표면으로 낮춰 대화 제목보다 앞서지 않게 했다.
- 나와 바로 대화하기는 포인트 표면, 캐릭터끼리 만나게 하기는 중립 표면으로 나눠 두 흐름의 차이를 표현했다.
- 수정은 포인트 의미, 삭제는 위험 의미로 분리했다.
- 상대 구분은 아바타·이름·관계 또는 외부 라벨을 함께 사용해 색상에만 의존하지 않는다.

## Tailwind 전환

- 두 새 대화 진입 카드의 기본·호버 상태를 Tailwind 유틸리티로 옮겼다.
- 기존 이벤트와 `al-*` 클래스는 유지했다.

## 검증

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`
- `dm-list.css` 직접 색상 및 대화방 셀렉터 부재 검사

실행 중인 프론트엔드가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다.

## 다음 단위

- DM 대화방을 헤더·대화 정체성·메시지 영역과 입력·보조 패널로 나눠 조사한다.
