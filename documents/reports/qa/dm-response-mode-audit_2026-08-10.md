# DM 응답 모드 흐름 감사

## 사용자 계약

하나의 DM 작성창에서 사용자는 답장의 맥락·품질·비용을 고르고, 선택한 단계에 맞는 AI 응답과 비용 안내를 받아야 한다.

| 단계 | 모델 | 비용 | 실제 차이 |
|---|---|---:|---|
| 기본 대화 | Gemini 2.5 Flash | 1C | 최근 10개 메시지, 기억 3개, 512 출력 토큰, 추론 없음 |
| 기억 반영 | Gemini 2.5 Flash | 2C | 최근 24개 메시지, 기억 6개, 768 출력 토큰, 256 추론 토큰 |
| 긴 맥락 | Gemini 2.5 Flash | 2C | 최근 48개 메시지, 기억 12개, 1,536 출력 토큰, 512 추론 토큰 |
| 중요한 답장 | Gemini 2.5 Pro | 5C | 최근 28개 메시지, 기억 12개, 1,536 출력 토큰, 256 추론 토큰 |
| 서사 집중 | Gemini 2.5 Pro | 7C | 최근 60개 메시지, 기억 12개, 3,072 출력 토큰, 1,024 추론 토큰 |

사진 첨부는 선택한 단계보다 이미지 이해 Flash 5C를 우선 적용한다. 자동 대화는 최대 6회 연속 생성이므로 기본 대화 흐름에 고정한다.

## 확인한 UX 보완

- 작성창에 현재 응답 모드·모델·비용을 항상 요약하고, 펼치면 다섯 단계의 차이를 비교한다.
- Pro는 구매 크레딧만 즉시 사용한다는 문구로 수정했다.
- 사진 첨부 중에는 이미지 이해 흐름으로 전환된다는 사전 안내를 표시한다.
- 비어 있는 대화의 시작 문장, 생성 중 상태, 실패한 사용자 입력 복원, 크레딧 부족 시 크레딧 화면 이동을 제공한다.
- 실패한 사용자 입력과 실패 안내는 하나의 미완료 턴으로 처리한다. 사용자가 새 메시지를 보내거나 자동 대화를 시작하면 이 턴을 모델 맥락과 화면에서 함께 제외한다.
- DM, 크레딧 카탈로그, 사용 내역, 서버 카탈로그에서 단계 명칭을 통일했다.

## 아직 증명되지 않은 항목

실행 중인 프런트가 없으므로 아래 관찰은 아직 실행하지 않았다.

1. 320px 폭과 낮은 화면 높이에서 모드 요약과 입력창이 동시에 접근 가능한지.
2. 서사 집중 선택 후 실제 `/api/ai/generate` 요청과 답변 표시가 자연스럽게 이어지는지.
3. 사진 첨부 시 모드 전환 안내·5C 상태·실제 이미지 생성 흐름이 일치하는지.
4. 구매 크레딧 부족 상태에서 크레딧 화면 이동 후 원래 DM으로 복귀하는지.

이 항목들은 실행 중인 프런트 프로세스가 연결된 뒤 Playwright 또는 브라우저 관찰로 확인해야 한다.
