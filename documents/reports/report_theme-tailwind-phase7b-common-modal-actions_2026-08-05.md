# 테마·Tailwind 7차 B 공통 모달 액션 보고서

## 작업 범위

- 채팅방 이름, 온보딩 이름, 캐릭터 삭제 모달을 전환했다.
- 페르소나 편집과 캐해 교정 입력·액션을 전환했다.
- 약관 동의와 콘텐츠 신고 입력·액션을 전환했다.

## 디자인 판단

- 저장·동의는 브랜드 포인트, 취소는 중립 표면, 삭제·신고는 위험 표면으로 통일했다.
- 입력은 떠 있는 표면과 포커스 포인트를 공유하도록 했다.
- 교정 빠른 선택은 포인트 면적을 작게 유지해 본문 입력보다 앞서 보이지 않게 했다.

## Tailwind 전환

공통 모달의 입력, 주·보조·위험 액션, 비활성 상태를 시맨틱 Tailwind 유틸리티로 옮겼다. 기존 `.al-*` 클래스는 레이아웃 호환을 위해 유지했다.

## 검증

- 공통 모달의 시맨틱 Tailwind 클래스 사용을 정적 계약 테스트로 고정했다.
- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`

실행 중인 프론트엔드가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다.
