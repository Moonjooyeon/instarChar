# 테마·Tailwind 4차 A 탐색 목록 화면 전환 보고서

## 작업 범위

- 탐색 헤더, 검색, 공유 링크 상태, 로딩·오류 상태, 빈 상태를 전환했다.
- 캐릭터 카드, 세계관 칩, 소유자·팔로워 정보, 태그와 카드 액션을 전환했다.
- 공개 프로필은 앱 공통 모달로 렌더링되므로 이번 범위에서 제외했다.

## 디자인 판단

- 캐릭터 카드는 중립 표면을 기본으로 두고 타임라인에 추가된 상태만 옅은 포인트 표면으로 구분했다.
- 태그는 별도 녹색 배경 조합을 제거하고 중립 배경 위 성공 의미색 텍스트로 정리했다.
- DM은 즉시 행동하는 주 액션, 타임라인 추가는 상태를 가지는 보조 액션으로 위계를 나눴다.
- 검색과 상태 제어는 카드보다 올라온 표면을 사용해 조작 영역과 콘텐츠 영역을 구분했다.

## Tailwind 전환

- DM 버튼과 타임라인 추가 버튼의 기본·활성·호버 상태를 Tailwind 유틸리티로 옮겼다.
- 기존 `on` 클래스와 이벤트 연결은 유지했다.

## 검증

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`
- `discover.css` 직접 색상 및 공개 프로필 셀렉터 부재 검사

실행 중인 프론트엔드가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다.

## 다음 단위
