# 테마·Tailwind 3차 C-1 피드 타임라인 기본 영역 전환 보고서

## 작업 범위

- 내 글·타임라인 탭, 빈 상태, 첫 글 안내, 생성 중·실패 상태를 전환했다.
- 게시물 헤더, 본문, 수정 입력, 인용, 이미지 설명, 분위기 카드, 좋아요, 관리 메뉴를 전환했다.
- 댓글 목록과 댓글 작성기는 다음 단위로 분리했다.

## 디자인 판단

- 탭 활성 상태는 진한 단색 대신 옅은 포인트 표면과 하단 선을 함께 사용해 라이트 모드에서도 과도하게 무겁지 않게 했다.
- 게시물 본문은 장식색을 제거하고 `ink`로 고정해 긴 글의 읽기 대비를 우선했다.
- 생성 중 상태는 브랜드 포인트 표면을 넓게 쓰되 채도를 낮춰 실제 게시물보다 앞서 보이지 않게 했다.
- 실패 상태는 테두리, 배경, 문구, 재시도 버튼을 동일한 위험 의미로 묶었다.
- 외부 캐릭터 구분은 파란색 추가 팔레트 대신 아바타 구조와 `추가한 캐릭터` 라벨을 유지해 표현했다.
- 좋아요 전용 의미 토큰을 Tailwind 색상으로 노출해 임의 핑크 유틸리티를 만들지 않았다.

## 회귀 방지

- 게시물 관리와 신고 분기는 변경하지 않았다.
- 탭의 기존 `on` 클래스는 유지해 레거시 동작과 스타일 연결을 보존했다.
- 댓글 셀렉터는 이번 스타일 브리지에 포함하지 않았다.
- 피드 전체 테마 활성화는 댓글과 도움말 전환 이후로 유지했다.

## 검증

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`
- `feed-timeline.css` 직접 색상 및 댓글 셀렉터 부재 검사

실행 중인 프론트엔드가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다.

## 다음 단위

- 댓글 목록, 댓글 수정, 작성자 선택, 입력과 전송 상태를 의미 토큰으로 전환한다.
