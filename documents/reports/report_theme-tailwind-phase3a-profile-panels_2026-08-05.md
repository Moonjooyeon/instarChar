# 테마·Tailwind 3차 A-2 피드 프로필 관계·기억 패널 전환 보고서

## 작업 범위

- 피드 프로필 도구 안의 관계 목록과 기억 목록만 이번 단위에 포함했다.
- 관계 카드, 호감도 상태, 기억 상대 목록, 기억 카드, 편집·추가 입력과 위험 액션을 의미 기반 테마 토큰으로 연결했다.
- 별도 관계·세계관·팔로워 모달과 피드 작성기·타임라인은 포함하지 않았다.
- 피드 전체의 `al-feed-theme-ready` 활성화는 작성기·타임라인·도움말 전환 이후로 유지했다.

## 디자인 판단

- 넓은 패널은 `surface-sunken`, 정보 카드는 `surface`, 입력은 `surface-raised`로 나눠 색상보다 깊이로 정보 위계를 만들었다.
- 삭제와 짝사랑 상태는 `danger` 계열로 한정해 위험·불균형 신호의 의미를 일관되게 유지했다.
- 고정 기억은 별도의 황색을 추가하지 않고 `accent-soft`와 `accent`로 표현해 제한된 브랜드 팔레트를 지켰다.
- 기억 추가 토글의 반복 클래스는 공통 Tailwind 상수로 묶어 두 위치의 상태 표현이 어긋나지 않게 했다.
- 키보드 사용을 위해 숫자 입력, 상대 카드, 기억 입력에 포커스 경계와 링을 추가했다.

## 회귀 방지

- 기존 `al-*` 클래스는 동작과 도움말 타깃 호환성을 위해 유지했다.
- 스타일 브리지는 `.al-feed-theme-ready` 아래에만 두어 아직 전환되지 않은 피드에서 부분 라이트 테마가 노출되지 않게 했다.
- 새 스타일 파일의 직접 색상은 불변 전경색 `#fff`만 허용했다.

## 검증

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`
- `feed-profile.css` 직접 색상 검사

실행 중인 프론트엔드 프로세스가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다. 따라서 이번 단위는 정적 검증까지만 수행하며 실제 라이트·다크 화면 검토는 피드 전환이 활성화된 뒤 진행한다.
