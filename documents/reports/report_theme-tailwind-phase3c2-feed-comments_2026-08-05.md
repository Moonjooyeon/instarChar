# 테마·Tailwind 3차 C-2 피드 댓글 전환 보고서

## 작업 범위

- 댓글 목록, 답글 대상, 수정 도구와 편집 입력을 전환했다.
- 댓글 작성 상자, 작성 계정 표시, 선택 칩, 입력과 전송 상태를 전환했다.
- 게시물 본체는 앞선 3C-1 스타일 브리지에 그대로 유지했다.

## 디자인 판단

- 댓글 본문은 게시물보다 한 단계 낮은 `soft` 명도로 두어 정보 위계를 유지했다.
- 작성 계정은 아바타와 계정명 문구를 함께 보여 색상만으로 화자를 구분하지 않게 했다.
- 댓글 작성 상자는 올라온 표면과 경계, 그림자를 함께 써 게시물 읽기 영역과 입력 영역을 분리했다.
- 페르소나 선택 상태의 별도 황색을 제거하고 브랜드 포인트 상태로 통일했다.
- 추가 액션은 성공 의미색, 삭제·신고 계열은 위험 의미색으로 제한했다.

## Tailwind 전환

- 댓글 달기 버튼과 전송 버튼의 기본·호버·비활성 상태를 Tailwind 유틸리티로 옮겼다.
- 기존 클래스와 이벤트는 유지해 댓글 열기, 전송, 키보드 입력 동작을 변경하지 않았다.

## 검증

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`
- `feed-comments.css` 직접 색상 검사

실행 중인 프론트엔드가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다.
