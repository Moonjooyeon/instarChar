# 테마·Tailwind 3차 D 피드 도움말 및 테마 활성화 보고서

## 작업 범위

- 피드 도움말 실행 버튼, 하이라이트, 탭 표시, 코치 카드와 이동 버튼을 전환했다.
- `FeedRoute`에 라이트·다크 테마 범위를 활성화했다.
- 포털로 렌더링되는 도움말에 독립 테마 범위를 추가했다.

## 발견과 해결

도움말은 `createPortal`로 `document.body` 아래에 렌더링되어 피드 루트의 테마 변수를 상속하지 않았다. 포털 콘텐츠를 `al-theme-ready al-feed-help-theme-ready` 래퍼로 감싸 라이트 테마 토큰을 독립적으로 받게 했다. 단계 계산, 타깃 측정, 닫기와 이동 이벤트는 변경하지 않았다.

## 디자인 판단

- 화면 차단막은 `scrim` 의미 토큰으로 분리해 라이트·다크에서 각각 필요한 명도를 제공한다.
- 코치 카드는 현재 테마의 올라온 표면을 사용하고, 하이라이트와 진행 상태에만 포인트 색을 집중했다.
- 이전 버튼은 중립 액션, 다음·완료 버튼은 주 액션으로 구분했다.
- 포털에서도 동일한 Pretendard 토큰을 사용해 글꼴 전환이 생기지 않게 했다.

## 피드 활성화 범위

- 프로필 기본 영역과 관계·기억 패널
- 작성기와 자동 글쓰기 설정
- 타임라인 상태와 게시물
- 댓글 목록과 작성기
- 피드 도움말

별도 공통 모달은 피드 루트 밖에서 렌더링되므로 이후 모달 단계에서 전환한다.

## 검증

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`
- `feed-help.css` 직접 색상 검사

실행 중인 프론트엔드가 없어 새 프로세스를 시작하지 않았다. 피드 라이트·다크 직접 화면 검증은 이미 실행 중인 앱이 제공될 때 수행해야 한다.

## 다음 단위

- 탐색 화면의 목록, 검색, 공개 프로필을 렌더링 소유권별로 조사하고 전환한다.
