# 테마·Tailwind 3차 B 피드 작성기 전환 보고서

## 작업 범위

- 피드 작성기의 장면 선택, 직접 작성, 자동 글쓰기 설정, 현재 상황 입력을 전환했다.
- 생성 중 상태와 생성 실패 상태는 타임라인 컴포넌트 소유이므로 다음 단위로 분리했다.
- 피드 전체 테마 범위는 아직 활성화하지 않았다.

## 디자인 판단

- 글 부탁하기는 브랜드 포인트가 드러나는 주 액션으로, 직접 쓰기는 중립 표면의 보조 액션으로 구분했다.
- 장면 선택은 같은 위계의 카드 버튼으로 유지하고 선택 전부터 과한 보라색 면적이 생기지 않게 했다.
- 고급 설정은 낮은 표면에 배치해 기본 작성 흐름과 시각적으로 분리했다.
- 자동 글쓰기 상태는 점, 문구, 카운트다운을 함께 사용해 색상 하나에만 의존하지 않는다.
- 레거시 펄스 애니메이션의 고정 핑크 값을 의미 토큰 기반 애니메이션으로 대체했다.

## Tailwind 전환

- 글 부탁하기, 직접 쓰기, 취소, 올리기 버튼의 색상과 상호작용 상태를 Tailwind 유틸리티로 옮겼다.
- 레이아웃과 동작 연결에 쓰이는 기존 `al-*` 클래스는 유지했다.
- 나머지 작성기 규칙은 `feed-composer.css`의 `.al-feed-theme-ready` 범위에서 의미 토큰으로 연결했다.

## 검증

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`
- `feed-composer.css` 직접 색상 검사

실행 중인 프론트엔드가 없어 새 프로세스를 시작하지 않았다. 피드 타임라인과 도움말까지 전환한 뒤 전체 범위를 활성화하고 라이트·다크 화면을 검토해야 한다.

## 다음 단위

- 타임라인의 첫 글 안내, 생성 상태, 탭, 게시물, 댓글을 렌더링 소유권별로 나눈다.
- 우선 타임라인 기본 게시물과 상태 UI를 전환한 뒤 댓글을 별도 검증한다.
