# 상단 라이트·다크 아이콘 토글 변경 보고서

## 변경 내용

- 홈 하단의 `기기 설정·라이트·다크` 선택기를 제거했다.
- 홈 상단 계정 바에 해·달 아이콘 토글을 배치했다.
- 로그인 화면의 기존 상단 아이콘 토글과 위치·동작을 통일했다.
- 최초 방문의 기기 설정 감지 로직은 유지했다.

## 배치 판단

전역 고정 버튼은 피드 도움말, 프로필 액션, DM 헤더와 겹칠 수 있어 사용하지 않았다. 테마를 선택하는 진입 화면인 로그인과 홈 상단에만 배치해 콘텐츠 액션과 충돌하지 않게 했다.

## 검증

- 상단 `ThemeToggle` 렌더링과 하단 선택기 제거를 정적 테스트로 고정했다.
- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- `git diff --check`

실행 중인 프론트엔드가 없어 프로젝트 규칙에 따라 새 프로세스를 시작하지 않았다.
