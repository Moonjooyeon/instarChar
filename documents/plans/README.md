## 새 계획 작성 기준

새 계획은 문제, 목표, 가정, 범위, 비범위, 영향 경계, 단계별 성공 기준, 검증 명령, 위험과 롤백을 포함한다. 구현이 끝나면 관련 보고서 또는 QA 문서에서 실제 결과를 남긴다.
