# AI 대화 경험 심화 개선 계획

> **Deprecated** — DM 사진 첨부 제거, 세 단계 응답 모드, 이어지는 추천 메시지 정책은 [DM 피드백 단순화 계획](plan_dm-feedback-simplification_2026-08-11.md)으로 대체됐다. 아래 내용은 2026-08-10 당시의 감사 기록이다.

## 목표

AI 캐릭터 DM을 단순 메시지 화면이 아니라, 사용자가 현재 대화의 정체성·맥락·진행 상태를 이해하고 다음 행동을 자연스럽게 선택할 수 있는 모바일 대화 경험으로 개선한다.

## 가정

- 현재 DM은 AI 캐릭터와의 역할극 대화이며, 일반 메신저보다 캐릭터성·장면·기억의 이해가 중요하다.
- 대화 생성, 기억 저장, 호감도 계산의 서버 계약은 이번 UI/UX 감사에서 변경하지 않는다.
- 화면 실행 프로세스가 없으므로 구현 전에는 코드·테스트·기존 API 계약을 근거로 판단하고, 실행 중 화면 검증은 별도 환경에서 한다.

## 범위

- DM 진입 화면, 스레드 헤더, 빈 대화 상태, 메시지 버블, 작성 영역, 응답 중/실패 상태를 감사한다.
- AI 채팅 제품의 모바일 패턴과 비교해 우선순위가 높은 프런트엔드 개선을 구현한다.
- 변경한 사용자 경험을 타입 검사, 도메인 테스트, 빌드 및 가능한 기존 프로세스 검증으로 확인한다.

## 제외 범위

- 새 AI 모델, 음성 대화, 결제 정책, 데이터베이스 스키마, 생성 프롬프트의 품질 변경
- DM 전체 정보 구조를 새 라우트나 전역 상태로 이전하는 대규모 리팩터링

## 영향 경로

사용자 대화 진입 → `DmThreadRoute` → `DmMessages`·`DmControls` → `useAliveDmGeneration.sendDM` → 생성 API → 응답/오류 메시지 → 스레드 상태

## 구현 단계

1. 현재 화면과 AI 채팅 사례를 기준으로 문제를 사용자 영향도 순으로 분류한다.
2. 모바일 우선순위·대화 정체성·실패 회복을 개선하는 최소 UI를 구현한다.
3. 변경 행동을 회귀 테스트에 추가하고, 정적·실행 중 검증을 구분해 결과를 남긴다.

## 성공 조건

- 사용자가 현재 누구와 어떤 상태로 대화하는지 작은 화면에서 즉시 알 수 있다.
- 빈 대화와 AI 응답 실패가 다음 행동을 명확히 제시한다.
- 대화 작성과 전송은 모든 모바일 높이에서 접근 가능하다.
- 기존 자동대화·화자 선택·이미지 첨부·전송 API 동작이 유지된다.

## 검증 계획

- `npm run typecheck`
- `npm run test:domain`
- `npm run build`
- 실행 중 프런트엔드가 있으면 320px 폭·낮은 높이에서 DM 진입, 설정 열기, 전송 성공/실패를 관찰한다.

## 위험과 롤백

- 설정을 접으면 발견성이 떨어질 수 있다. 현재 화자 상태를 요약해 표시하고, 자동대화는 설정 안에서 명시적으로 유지한다.
- 생성 실패 UI를 변경하면 기존 오류 문자열에 의존하는 테스트가 깨질 수 있다. 기존 실패 원인은 보존하고 행동만 추가한다.
- 회귀가 확인되면 변경한 DM 화면·스타일 파일만 이전 구조로 되돌릴 수 있다.

## 결과

- 모바일 스레드는 작성 영역을 우선 배치하고, 설정·기억·호감도는 화면 높이에 맞춰 읽을 수 있게 정리했다.
- 빈 대화에는 수정 가능한 첫 장면 문장을, 생성 실패에는 입력 복원 행동을 추가했다.
- 응답 생성과 자동 대화의 진행 상태가 화면에 드러나도록 보완했다.

## 2차 DM 응답 모드 감사

### 확인한 단절

- DM 작성창의 응답 모드와 크레딧 화면의 기능명·설명이 서로 달랐다.
- Pro 모드는 구매 크레딧만 사용하지만, 작성창 안내가 에너지 대체 사용처럼 보였다.
- 사진을 첨부하면 이미지 이해 흐름이 우선되는데도, 모드 선택 화면에서 이 전환이 충분히 드러나지 않았다.

### 보완 기준

- 수동 DM에는 기본·기억 반영·긴 맥락·중요한 답장·서사 집중의 다섯 단계를 같은 이름으로 노출한다.
- 각 단계는 서버 flow, 모델, 입력 맥락 범위, 응답 한도, 크레딧 안내가 함께 일치해야 한다.
- 자동 대화는 여러 번 연속 생성되므로 기본 대화 흐름으로 고정한다.
- 사진 첨부 시에는 이미지 이해 5C가 우선된다는 사실을 보내기 전에 명시한다.
