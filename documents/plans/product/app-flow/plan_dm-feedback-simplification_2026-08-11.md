# DM 이미지 이해 제거·응답 모드 단순화·대화 추천 메시지 확장

## Problem

DM의 사진 첨부는 별도 5C 이미지 이해 흐름으로 처리되고, 응답 모드는 1C·2C·2C·5C·7C의 다섯 단계라 선택 피로가 있다. 대화 시작 화면의 추천 메시지는 첫 메시지 전에만 보여서, 대화가 이어진 뒤에는 사용자가 다음 말을 직접 떠올려야 한다.

## Outcome

AI는 어떤 사용자 이미지도 입력으로 해석하지 않으며, DM 응답 모드는 의도가 분명한 세 단계만 남는다. 대화가 시작된 뒤에도 상대 캐릭터의 마지막 답장 아래에 다음 말을 고를 수 있는 추천 메시지가 나타난다. 추천 메시지를 누르면 입력창에만 채워지고 즉시 전송하거나 크레딧을 쓰지 않는다.

## Evidence

- DM 사진 첨부와 `image_understanding` 5C 흐름은 `apps/frontend/src/app/dm/DmControls.tsx`, `apps/frontend/src/hooks/useAliveDm.ts`, `apps/frontend/src/hooks/useAliveDmGeneration.ts`, `backend/app/core/credit_policy.py`에 연결돼 있다.
- 서버는 `backend/app/services/media_ai.py`에서 AI 요청의 `image_url`을 실제 이미지 데이터로 바꾼다. 피드 생성·댓글 생성도 `image_url`을 보낼 수 있으므로 DM 화면만 숨기면 이미지 이해가 완전히 제거되지는 않는다.
- 현재 응답 모드는 `apps/frontend/src/domain/dm/dmResponseMode.ts`의 다섯 흐름이며, 각 흐름은 크레딧 정책·API 카탈로그·AI 테스트에도 등록돼 있다.
- 현재 추천 메시지 `DmStarters`는 `apps/frontend/src/app/dm/DmMessages.tsx`에서 `dm.length === 0`일 때만 표시된다.

## Assumptions and decisions

- 확정: DM 사진 첨부와 별도 5C `image_understanding` 흐름만 삭제한다. 프로필·갤러리·피드의 사진 저장·표시와 피드 AI의 이미지 참조는 유지한다.
- 확정: DM 응답 모드는 `기본 대화(1C)`, `기억 반영(2C)`, `중요한 답장(5C)`의 세 단계로 유지한다. `긴 맥락(2C)`은 기억 반영으로, `서사 집중(7C)`은 중요한 답장으로 흡수한다.
- 확정: 첫 화면의 추천 메시지는 유지하고, 이후에는 상대 캐릭터가 답장한 뒤 입력창이 비어 있을 때만 동일한 위치에 `다음 이야기` 추천 3개를 노출한다. 자동 대화 중·이미 작성 중일 때는 숨긴다.
- 추천 메시지는 새 AI 호출 없이 대화 차수와 마지막 답장으로 선택되는 문장 풀에서 구성한다. 초반 3개 고정 문구와 반복되지 않도록 최소 12개 이상의 후보를 둔다.

## Scope

1. `image_understanding` 정책·카탈로그·DM 사진 첨부와 해당 DM 생성 분기를 제거하고 관련 테스트를 갱신한다.
2. 세 DM 응답 모드 외의 정책, 프런트 모드 목록, 저장된 선택값의 안전한 기본값을 정리한다.
3. 첫 대화 및 계속되는 대화에 재사용할 추천 메시지 컴포넌트를 만들고, 마지막 답장 뒤에 노출 조건을 적용한다.
4. 크레딧 표시, 입력·전송 동작, 모바일 레이아웃을 회귀 검증한다.

## Non-goals

- 프로필·갤러리·피드의 사진 업로드, 보관, 표시는 제거하지 않는다.
- 대화 추천을 위해 추가 AI 호출이나 새 크레딧 상품을 만들지 않는다.
- 기존 사용 기록의 과거 `image_understanding` 행은 삭제하거나 재작성하지 않는다.
- 대화 추천을 개인화·학습하는 시스템은 이번 범위에 넣지 않는다.

## Acceptance criteria

- [x] DM 입력창에 사진 첨부 버튼·미리보기·사진 답장 비용이 없다.
- [x] DM 사진 첨부가 새 AI 요청에 `image_url`을 전달하지 않는다.
- [x] 크레딧 카탈로그와 사용 내역 라벨에서 이미지 이해가 신규 선택지로 노출되지 않는다.
- [x] DM 응답 모드는 1C·2C·5C 세 개이며 서버 비용 정책과 프런트 표시가 일치한다.
- [x] 이전에 삭제된 모드가 저장돼 있어도 기본 대화로 안전하게 전환된다.
- [x] 첫 메시지 전과 상대 답장 후에 추천 메시지가 보이고, 선택 시 입력창만 채워진다.
- [x] 추천 메시지는 자동 대화 중이거나 입력 초안이 있을 때 나타나지 않는다.

## Risks and next mode

5C `중요한 답장`은 기존 7C보다 출력과 추론 예산이 작다. 실제 대화에서 긴 서사가 부족하다는 피드백이 나오면 5C 모드의 품질 설정만 별도 조정한다. Android 자산 동기화와 정적·정책 검증은 완료했지만, 로그인된 실제 DM 화면에서의 수동 클릭 검증은 아직 수행하지 않았다.
